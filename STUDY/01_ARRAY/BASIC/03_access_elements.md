# Accessing Elements

## 📌 Syntax
arr[index]

## ✅ Example
int[] arr = {10, 20, 30};

System.out.println(arr[0]); // 10
System.out.println(arr[1]); // 20

## 🧠 Key Points
- Index starts from 0
- arr[0] → first element
- arr[n-1] → last element

## ⚠️ Mistakes
- arr[3] in size 3 → error
- Negative index not allowed

## 🔁 Revision Points
⭐ Use square brackets []  
⭐ Index important concept
