# Memory Allocation in Arrays

## 📌 Concept
Arrays store elements in contiguous memory locations.

## 🧠 What Happens Internally?
- Memory is allocated in heap
- Reference stored in stack
- All elements stored continuously

## ✅ Example
int[] arr = new int[3];

Memory:
[0] [0] [0]

## 🔑 Key Points
- Default values:
  int → 0
  boolean → false
- Fixed size
