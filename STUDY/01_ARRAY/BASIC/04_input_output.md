# Input & Output in Arrays

## 📌 Taking Input
Scanner sc = new Scanner(System.in);
int n = sc.nextInt();

int[] arr = new int[n];

for(int i = 0; i < n; i++) {
    arr[i] = sc.nextInt();
}

## 📌 Printing Output
for(int i = 0; i < n; i++) {
    System.out.print(arr[i] + " ");
}

## 🧠 Key Points
- Loop required
- Use Scanner for input

## 🔁 Revision Points
⭐ Loop is must  
⭐ Input + Output both use loop
