# Length Operator

## 📌 Syntax
arr.length

## ✅ Example
int[] arr = {10, 20, 30};

System.out.println(arr.length); // 3

## 🧠 Key Points
- Returns size of array
- Used in loops

## ⚠️ Mistakes
- arr.length (correct)
- arr.length() (wrong ❌)

## 🔁 Revision Points
⭐ No brackets ()  
⭐ Used for loop condition
