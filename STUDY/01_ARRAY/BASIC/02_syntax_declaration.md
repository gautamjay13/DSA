# Syntax & Declaration

## 📌 Syntax
int[] arr = new int[5];

## 🧠 Explanation
- int[] → data type
- arr → array name
- new int[5] → creates array of size 5

## ✅ Example
int[] arr = new int[3];
arr[0] = 10;
arr[1] = 20;
arr[2] = 30;

## ⚠️ Mistakes
- Cannot access index >= size
- Array size is fixed
